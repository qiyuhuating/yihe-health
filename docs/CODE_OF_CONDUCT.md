# 社区行为准则

本项目参考 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html) 制定本准则，适用于颐和智慧养老管理平台的贡献者、维护者与参与讨论的用户。

## 共同约定

欢迎不同背景、技术水平与经验的参与者。请聚焦于具体问题、可复现事实、用户影响以及代码和文档本身，尊重审查意见与合理分歧。

鼓励的行为包括：尊重沟通对象；明确、建设性地提出问题和改进建议；耐心处理技术反馈；尊重老年用户、家属与照护人员的实际使用处境。

以下行为不可接受：

- 骚扰、性骚扰、威胁、歧视、羞辱或针对个人的持续攻击；
- 在 Issue、PR 或其他项目空间发表侮辱性、煽动性言论或故意干扰讨论；
- 未经许可公开他人的私人联系方式、凭据、身份资料或照护数据；
- 发布真实长者或家属的健康、定位、数据库记录及其他敏感信息；
- 其他明显违背专业协作与参与者安全的行为。

## 适用范围与执行

本准则适用于仓库 Issue、Pull Request、Discussions、代码审查，以及以本项目名义开展的线上或线下活动。

维护者可以依据行为严重程度采取提醒、警告、编辑或移除不当内容、限制参与等措施。处置应根据可核实事实、适用的平台规则和必要的隐私保护进行，不承诺固定的响应时间。

## 反馈与隐私

如遇骚扰或其他行为准则问题，请**私下**联系仓库维护者；勿在公开 Issue 中披露受害人资料或私人对话。若涉及可被利用的安全漏洞，请改按 [安全政策](../.github/SECURITY.md) 中的私密渠道报告。

举报时提供必要的发生位置、时间和相关证据即可。维护者应尽可能限制信息传播，但不能将本准则理解为对保密性或处理时效的绝对保证。
