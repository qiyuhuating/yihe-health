# 颐和 2.1.0

这是稳定渠道发布。

## 变更

- 移植岁宁 PR #212 的后端性能优化，包括健康样本写入、历史载荷复用、版本区间分配、规则任务调度、SOS 准入及计算热路径。
- 保留 MySQL 8.4 为唯一权威数据库，不降低同步持久性要求。适配颐和的客户端、手表同步和部署配置。

## 升级与恢复

升级前备份数据库和数据加密密钥，并停止全部旧版本写入进程。使用独立测试库验证迁移与恢复方案后再升级；新旧写入进程不得混合运行。若升级失败，停止服务并按已验证的备份恢复流程处理，不直接重放结果不确定的写入。

## 验证边界

本文件说明候选版本的变更和升级要求，不代表正式发布、生产迁移、真实设备或持续负载验收已经完成。以对应提交的 CI 与发布清单为准。
