# 旧产品测试保留区

三个文件保留搬移前的原文，共 45 个旧用例。这里不含 __init__.py，不参与当前 unittest 默认发现；不能宣称这 45 项在新版本通过。它们引用旧 DOM、旧 API，且其 ROOT 路径仍是旧目录布局，仅作为历史验收依据，需放回旧版本 tests 目录运行。

聊天/密钥/资讯/入出院/行程/复杂 CSV 和 PDF 等断言因用户明确删除对应产品功能而退役，不以跳过断言掩盖当前功能失败。

保留能力已在 test_community.py 和 care-domain.test.cjs 重写验证：分页与空结果、跨标签竞争与同步、存储失败、日志轮转和篡改检测、主题迁移/失败回滚、姓名打码导出、联系人档案持久化、公共表单失败、键盘对话框、四种宽度布局，以及三条完整事件处置流程。

公共页对比度/触控尺寸数值、200% 缩放与组件预览视觉断言已按当前 DOM 重写迁移到 test_community.PublicPagesTests，覆盖 6 个公共页、登录页与组件校对页：触控目标 44px、主行动在明暗主题下的对比度、真实 200% 缩放无横向溢出、预览页的种子数据/主题开关/弹窗焦点/反馈文案与徽标对比度。200% 缩放改用 CSS 视口减半 + deviceScaleFactor 2 的真实模拟；旧的 body.style.zoom 代理不触发媒体查询重排，会对固定最小列布局误报溢出，故不再使用。不将新测试通过等同于已退役功能（聊天/密钥/资讯/入出院/行程/复杂报表）的旧断言通过。新事件模型的来源恢复、恶化再提醒、升级、幂等和并发在独立 Node 测试中覆盖。
